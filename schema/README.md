# Schema

This directory contains data structure definitions written as JSON schema.
In the sub-directories there are various definitions of request and response
formats also as JSON schema.

Some experimenting has been made to build OpenAPI specification from these files
but not succeeded.

Files are used to generate Typescript defintions, to validate requests in backend
and also in API tests to validate result of an API call.

A file `openapi.json` is just experimenting. No real content yet.
