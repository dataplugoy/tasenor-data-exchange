# Example

In this example we show step by step how the automation works from Nordnet to Procountor.

<figure><figcaption>**Step 1**: *Download transactions from [Nordnet](https://www.nordnet.fi) in CSV format (Nordnet will provide automatic API in 2024-2025).*</figcaption>![Step 1](/demo-step1-nordnet.png)</figure>

<figure><figcaption>**Step 2**: *Log in to [TaDeX App](https://tadex-app.tasenor.com/) and create new flow plan for the transfer. You need your API-key from Procoutor.*</figcaption>![Step 2](/demo-step2-nordnet.png)</figure>

<figure><figcaption>**Step 3**: *Press **Run** button and it will ask for CSV-file to upload.*</figcaption>![Step 3](/demo-step3-nordnet.png)</figure>

<figure><figcaption>**Step 4**: *During the analysis it may ask questions allowing you to fine tune future behaviour. We didn't have any money for buying in this case, we might use separate account for negative balance.*</figcaption>![Step 4](/demo-step4-nordnet.png)</figure>

<figure><figcaption>**Step 5**: *Once done, you will see completed progress bar with number **7** denoting the successful transactions extracted. Click it and you see the steps executed.*</figcaption>![Step 5](/demo-step5-nordnet.png)</figure>

<figure><figcaption>**Step 6**: *Click a step and you can see details what has been going on under the hood.*</figcaption>![Step 6](/demo-step6-nordnet.png)</figure>


<figure><figcaption>**Step 7**: *Newly found transactions are delivered to the [Procountor](https://procountor.fi/).*</figcaption>![Step 5](/demo-step7-nordnet.png)</figure>
