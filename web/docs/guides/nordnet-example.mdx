# Example

In this example we show step by step how the automation works from Nordnet to Procountor.

<figure>
<figcaption>**Step 1**: *Download transactions from [Nordnet](https://www.nordnet.fi) in CSV format (Nordnet will provide automatic API in 2024-2025).*</figcaption>
![Step 1](/demo-step1-nordnet.png)
</figure>

<figure>
<figcaption>**Step 2**: *Log in to [TaDeX App](https://tadex-app.tasenor.com/) and create new flow plan for the transfer. You need your API-key from Procoutor.*</figcaption>
![Step 2](/demo-step2-nordnet.png)
</figure>

<figure>
<figcaption>**Step 3**: *Press **Run** button and it will ask for CSV-file to upload.*</figcaption>
![Step 3](/demo-step3-nordnet.png)
</figure>
