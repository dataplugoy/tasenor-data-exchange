# Example

In this example, we show step by step how the automation works from Nordnet to Procountor.

<figure><figcaption>**Step 1**: Download transactions from [Nordnet](https://www.nordnet.fi) in CSV format (Nordnet will provide automatic API by 2024-2025).</figcaption>![Step 1](/demo-step1-nordnet.png)</figure>

<figure><figcaption>**Step 2**: Login to the [TaDeX App](https://tadex-app.tasenor.com/) and create a new flow plan for the transfer. You need your [API-key from Procountor](https://support.procountor.fi/hc/fi/articles/4984567268509-API-k%C3%A4ytt%C3%B6%C3%B6notto).</figcaption>![Step 2](/demo-step2-nordnet.png)</figure>

<figure><figcaption>**Step 3**: Press **Run** button and it will ask for CSV-file to upload.</figcaption>![Step 3](/demo-step3-nordnet.png)</figure>

<figure><figcaption>**Step 4**: During the analysis stage, you might receive questions that help you fine-tune future behaviour. Here we could use a separate account for negative balance, since we lacked funds to make purchases.</figcaption>![Step 4](/demo-step4-nordnet.png)</figure>

<figure><figcaption>**Step 5**: When encountered the first time, you need to select destination accounts provided by Procountor for various purposes.</figcaption>![Step 5](/demo-step5-nordnet.png)</figure>

<figure><figcaption>**Step 6**: Once done, you will see a progress bar showing the number 7. This means the extraction of seven transactions was successful. Click it to see the steps executed.</figcaption>![Step 6](/demo-step6-nordnet.png)</figure>

<figure><figcaption>**Step 7**: By clicking on a step, you can see the specific details of the background activities.</figcaption>![Step 7](/demo-step7-nordnet.png)</figure>

<figure><figcaption>**Step 8**: Any newly identified transactions are sent to [Procountor](https://procountor.fi/).</figcaption>![Step 8](/demo-step8-nordnet.png)</figure>
