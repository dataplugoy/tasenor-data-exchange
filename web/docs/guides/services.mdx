# Services

External services are used when processing the flow plans. They provide exchange rates for currencies and crypto
currencies not given in the imported files, like in Lynx statements, and information about instruments.

The services are managed on the **Services** page. They belong to the user and are used by all flow plans of the
user.

| Service | Provides | Settings |
|---------|----------|----------|
| Tasenor Bookkeeper | Currency and crypto rates | Address of the bookkeeper API, user and password |
| Coinbase Exchange prices | Crypto rates from the public market data of Coinbase, no account needed | Address of the API |
| OpenFIGI | Instruments by ISIN code | Address of the API and an optional API key |
| JSON files | Currency and crypto rates from files | Only for testing |

Passwords and keys are stored encrypted and never shown after saving. When editing a service, leave the field empty to keep the saved
one.

**Test** makes a sample query for everything the service provides, e.g. the rate of USD in EUR yesterday, and shows
the answer or the error for each.

A service providing several things can be limited with **Use for**, e.g. to use the bookkeeper only for currency
rates when it cannot give crypto rates.

When several services provide the same thing, they are asked in the order they were added until one answers. For
example, crypto rates can come from Coinbase Exchange prices when the bookkeeper cannot provide them. Coinbase
Exchange prices are the prices of the trading minute at the time asked. Assets without a euro market are priced
through BTC or USD.

A service marked **free** is also used by the command line tool.
