# Features

## General

* For mobile and desktop
* Configuration is done only when needed to speed up introducing the system into use
* When both the source and destination support the API, it operates seamlessly without requiring a login
* When processing without logging in, you can expect to receive questions that need to be answered via email
* Managing duplicates to prevent creating duplicate transactions when reprocessing the same data
* High accuracy math

## Investment bookkeeping

* Deposits and withdrawals
* Dividends
* Foreign exhcange operations
* Tracking all stock purchase prices
* Recording of losses and profits
* Stock splits and renamings
* Debt accounts for margin loans

## Bank statements

* Nordea TITO statements, several accounts in one file
* Rules created from the lines of the statement with a form based editor and a live preview
* Lines without a rule are asked and can be handled once
* Categories for expenses and income, mapped to the accounts of the bookkeeping
* VAT included in expenses and income

## Developer Oriented

* Easy implementation of new information sources and destination bookkeeping systems
* A customizable rule system for other information sources, such as generic bank statements
