# Features

## General

* For mobile and desktop.
* When both source and destination supports API, it operates automatically without login.
* When processing without login, you get questions requiring some input by email.

## Investment bookkeeping

* Deposits and withdrawals.
* Dividends.
* Foreign exhcange operations.
* Complete tracking of stock buying prices.
* Recording of losses and profits.
* Stock splits and renamings.
* Debt accounts for margin loans.

## Developer Oriented

* Easy to implement new information sources and destination bookkeeping systems.
* Customizable rule system for other information sources like generic bank statemets.
