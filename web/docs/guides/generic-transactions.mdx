# Generic Transaction

Prior to their delivery, unified items are converted into *generic transactions*. The JSON object is compact and contains the information for delivery. However, the accounts in the target systems remain unknown until the actual delivery. Therefore, they are depicted as symbols that represent the purpose of the account.

The generic transaction looks like this:
```json
  {
    "time": "2000-05-05T13:40:11",
    "lines: [
      {
        "account": "CURRENCY_EUR",
        "amount": "-21062.05",
        "text": "Bought +100 AAPL",
        "extras": {
          "tags": ["Nordnet"]
        }
      },
      {
        "account": "STOCK",
        "amount": "21062.05",
        "text": "Bought +100 AAPL",
        "extras": {
          "tags": ["Nordnet"]
          "asset": "AAPL"
          "assetChange": "100"
        }
      }
    ]
  }
```

The fields above are:
* **time** The transaction’s timestamp. If only the date is known, time will default to midday.
* **lines** Each transaction line to be added to the bookkeeping.
* **account** Symbolic name for the account. Each bookkeeping system will have its own configuration for mapping symbols to actual accounts.
* **text** Description obtained from the statement or created automatically for the event.
* **extras** Various optional fields:
  * **tags** Optional dimensions recorded by the bookkeeping system.
  * **asset** For accounts with assets, this is the ticker.
  * **assetChange** The number of units of assets added or removed in this transaction.
