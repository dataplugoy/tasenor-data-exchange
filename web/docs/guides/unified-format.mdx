# Unified Format

Unified format is a rich JSON format to express all possible transactions supported
and understood by TaDeX. It also allows incompleteness to some extend. Enything that
can be resolved in analysis step, can be left out. For example, if the actual currency
exchange rate is not given, it is fetched from the third party as long as the date
of the transaction is known.

## Common Fields

### `type` (<Type file="UnifiedItemData.json" field="type"/>)

This defines the idea of the transaction. Each *type* of transaction has different
fields it requires by default and some of the fields it can determine according to the type.
Supported types are <TxTypes/>.

### `value` (<Type file="UnifiedItemData.json" field="value"/>)

The is positive or zero value determining *total value* of the transaction. That must
include additional fees for example. Value can be given either as number or as
high precision string. Value is measured in *default currency* of the flow plan.

### `text`

Meny transaction types can determine description on its own in the default language
of the flow plan. If text field is given, it overrides the generated default text.


## Some Optional Fields

### `valueAsset`

It is not necessary to define total value in default currency. If some other currency
or crupto currency is used instead, this field can name it.

### `rates`

If conversion rates from other currencies to the default currency is known, it can
be given here. Otherwise it is resolved using other services. The format of this field
is a map from the currency name(s) to the conversion rate(s) in the default currency.

## Assets

```
    "assetIn": {
      "description": "In case of buying some asset, this is the asset received.",
      "$ref": "Asset.json"
    },
    "assetAmountIn": {
      "description": "In case of buying some asset, this is the number of assets received.",
      "type": ["number", "string"],
      "pattern": "^[0-9]+(\\.[0-9]+)?$"
    },
    "assetValueIn": {
      "description": "In case of buying some asset, this is the value of assets in the default currency.",
      "type": ["number", "string"],
      "pattern": "^[0-9]+(\\.[0-9]+)?$"
    },
    "assetTypeIn": {
      "description": "Type of the asset received.",
      "type": "string",
      "pattern": "^(STOCK|CRYPTO)$"
    },

    "assetOut": {
      "description": "In case of selling some asset, this is the asset traded out.",
      "$ref": "Asset.json"
    },
    "assetAmountOut": {
      "description": "In case of selling some asset, this is the number of assets given (as positive number).",
      "type": ["number", "string"],
      "pattern": "^[0-9]+(\\.[0-9]+)?$"
    },
    "assetValueOut": {
      "description": "In case of selling some asset, this is the value of assets in the default currency (as positive number).",
      "type": ["number", "string"],
      "pattern": "^[0-9]+(\\.[0-9]+)?$"
    },
    "assetTypeOut": {
      "description": "Type of the asset given.",
      "type": "string",
      "pattern": "^(STOCK|CRYPTO)$"
    },
```

## Fees

```
    "fee": {
      "description": "Amount of fee charged as a part of the transaction.",
      "type": ["number", "string"],
      "pattern": "^[0-9]+(\\.[0-9]+)?$"
    },
    "feeAsset": {
      "description": "Ticker of the fee charged as a currency or other asset ticker.",
      "$ref": "Asset.json"
    },
```

  The difference between types *fee* and *expense* is that the fee is added as an additional line to other transaction
  like selling or buying stocks. An expense contributes completely separate independent transaction
  on its own.

## Taxes

```
    "taxType": {
      "description": "If tax must be calculated, this is the type of the tax.",
      "type": "string",
      "enum": ["vat", "withholding"]
    },
    "taxAmount": {
      "description": "If tax must be calculated, this is the amount of tax in tax assets.",
      "type": ["number", "string"],
      "pattern": "^[0-9]+(\\.[0-9]+)?$"
    },
    "taxAsset": {
      "description": "If tax must be calculated, this is the asset used (defaults to `valueAsset`)",
      "$ref": "Asset.json"
    },
    "taxPercentage": {
      "description": "If tax must be calculated, alternatively it can be percentage of the total of the transaction.",
      "type": "number"
    },
```
