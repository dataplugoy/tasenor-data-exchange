# Yleistetty Tilitapahtuma (english)

Before the final transactions are delivered, the unified items are transformed to *generic transactions*.
It presents a compact JSON object containing information to be delivered. However, for example, accounts
in the target systems are not known before actualy delivery. They are presented as symbols to describe
the purpose of the account.

The generic transaction looks like this:
```json
  {
    "time": "2000-05-05T13:40:11",
    "lines: [
      {
        "account": "CURRENCY_EUR",
        "amount": "-21062.05",
        "text": "Bought +100 AAPL",
        "extras": {
          "tags": ["Nordnet"]
        }
      },
      {
        "account": "STOCK",
        "amount": "21062.05",
        "text": "Bought +100 AAPL",
        "extras": {
          "tags": ["Nordnet"]
          "asset": "AAPL"
          "assetChange": "100"
        }
      }
    ]
  }
```

The fields above are:
* **time** Time stamp of the transaction. If only the date is known it has time added pointing to the midday.
* **lines** Each transaction line to be added to the bookkeeping.
* **account** Symbolic name of the account. The mapping from symbols to the actual account will be configured for each bookkeeping system separately.
* **text** Description either taken from the statement or automatically constructed for the event.
* **extras** Various optional fields:
  * **tags** Optional dimensions known by the bookkeeping.
  * **asset** If account holds assets, this is the ticker of the asset.
  * **assetChange** How many units of the asset has been added or removed from the account in this transaction.
