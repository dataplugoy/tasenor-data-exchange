# Ominaisuudet

## Yleiset

* Sekä mobiiliin että työpöydälle.
* Konfigurointi tehdään lennosta sitä mukaa kuin tarvitaan.
* Kun sekä lähdejärjestelmä että kirjapito tukee APIa, tiedot siirtyvät automaattisesti.
* Kun prossointi on täysautomaattista, saat mahdolliset konfigrointikysymykset suoraan sähköpostiisi.
* Huolellinen varmistus ettei samoja tapahtumia kirjata kahdesti vaikka sama tieto syötettäisiin uudelleen.
* Korkean tarkkuuden matematiikka käytössä.

## Osakesijoittajalle

* Nostot ja talletukset.
* Osingot.
* Valuutanvaihdot.
* Tarkka ostohintojen ja insttrumenttimäärien seuranta.
* Myyntivoittojen ja -tappioiden kirjaaminen.
* Osakkeiden splittaus ja uudelleennimeäminen.
* Erilliset velkatilit marginaalilainaukselle.

## Sovelluskehittäjille

* Helppoa toteuttaa uusia tietolähteitä tai kirjanpitokohteita.
* Muokattava sääntösysteemi monimutkaisemmille tietolähteille kuten pankin tiliotteille.
