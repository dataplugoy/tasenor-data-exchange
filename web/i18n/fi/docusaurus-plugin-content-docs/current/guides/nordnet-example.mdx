# Esimerkki

Tässä esimerkissä näytämme kuinka helposti tapahtumat siirtyvät Nordnetistä Procountoriin.

<figure><figcaption>**Vaihe 1**: Nouda lista tilitapahtumista [Nordnetistä](https://www.nordnet.fi) CSV-muodossa (Nordnet on aikeissa tarjota automaatio APIn joskus 2024-2025).</figcaption>![Vaihe 1](/demo-step1-nordnet.png)</figure>

<figure><figcaption>**Vaihe 2**: Kirjaudu [TaDeX sovellukseen](https://tadex-app.tasenor.com/) ja luo tietovirtasuunnitelma Nordnetistä Procountoriin. Tarvitset siihen [API-avaimen Procountorilta](https://support.procountor.fi/hc/fi/articles/4984567268509-API-k%C3%A4ytt%C3%B6%C3%B6notto).</figcaption>![Vaihe 2](/demo-step2-nordnet.png)</figure>

<figure><figcaption>**Vaihe 3**: Paina **Run** painiketta ja valitse CSV-tiedosto lähetettäväksi.</figcaption>![Vaihe 3](/demo-step3-nordnet.png)</figure>

<figure><figcaption>**Vaihe 4**: Analyysivaiheessa saatta nousta kysymyksiä, joiden perusteella nykyistä ja tulevaa toiminnallisuutta voidaan muokata.Tässä esimerkissä meillä ei ole tilillä varoja ostoihin, joten selvitetään, että halutaanko negatiivinen saldo kirjata erilliselle velkatilille.</figcaption>![Vaihe 4](/demo-step4-nordnet.png)</figure>

<figure><figcaption>**Vaihe 5**: Kun ajo valmistuu, edistymistä ilmaisevan palkin vieressä on numero 7. Se kertoo, että seitsemän tapahtumaa on luotu onnistuneesti. Klikkaamalla palkkia pääset tutkimaan suoritettuja vaiheita.</figcaption>![Vaihe 5](/demo-step5-nordnet.png)</figure>

<figure><figcaption>**Vaihe 6**: Yksittäistä vaihetta klikkaamalla pääset tarkastelemaan tarkemmin mitä kyseisessä vaiheessa on tehty.</figcaption>![Vaihe 6](/demo-step6-nordnet.png)</figure>


<figure><figcaption>**Vaihe 7**: Luodut tapahtumat löytyvät nyt [Procountorista](https://procountor.fi/).</figcaption>![Vaihe 5](/demo-step7-nordnet.png)</figure>
